## ID 规则（定稿，严格遵守）
- 基准：`beat_001`、`beat_002`……（全卷线性递增）
- **拆分一层**：`beat_004` → `beat_004A / beat_004B / beat_004C`
- **拆分二层**（**仅到 Aa 这一级为止**）：`beat_004Aa`
  - ⚠️ **禁止再往 Aa 以下细分**（不得 `Aa1`/`Aaa`）；需要更细时必须问用户
  - ⚠️ **禁止 `AA`/`AB` 级**——大写后缀只到单个字母
- **合并**：`beat_001` + `beat_002` → `beat_1_2`（下划线连接）
- **删除**：直接删，保留号不补号
- **跨卷移动**：带卷前缀，如 `V4beat_003`
