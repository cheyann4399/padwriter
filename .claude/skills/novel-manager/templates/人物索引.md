# 人物索引

> 由创作总管（Claude）自动维护，你无需手动编辑。
> 一个人物只存一次完整设定（在「设定库/L1核心铁则/」或「L2体系设定/」对应的文件里），此处只做 **ID → 出场节拍** 的关联。

## ID 规则
- 人物 ID：`char_001`、`char_002`……单人物唯一，终身不变
- 出场节拍：跟随你所定的节拍 ID（如 `beat_001`、`beat_004A`、`beat_1_2`）
